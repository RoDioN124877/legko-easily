# speedtest-cli

Консольная утилита на TypeScript (Node.js) для замера скорости скачивания. Делает **10 последовательных запросов** к указанному адресу, каждый раз дожидаясь полного ответа, и печатает среднее время запроса, общий объём данных и скорость скачивания.

Без runtime-зависимостей: встроенные `fetch`, `node:util`, `node:test`.

## Требования

Node.js **20+** (проверено на 24) и npm.

## Установка и запуск

```bash
npm install
npm run build
node dist/cli.js <URL>
```

Пример (тяжёлая картинка / тестовый файл):

```bash
node dist/cli.js "https://speed.cloudflare.com/__down?bytes=10000000"
```

Можно и через npm: `npm start -- <URL>`.

### Параметры

| Параметр | Описание | По умолчанию |
|---|---|---|
| `-n`, `--requests <n>` | число запросов (1–1000) | `10` |
| `-t`, `--timeout <сек>` | таймаут одного запроса | `30` |
| `-u`, `--unit <unit>` | `mbit` (Мбит/с) или `mbyte` (МБ/с) | `mbit` |
| `--json` | вывод в JSON (для скриптов) | — |
| `--no-color` | без цветов (также учитывается `NO_COLOR`) | — |
| `-h`, `--help` | справка | — |

Коды выхода: `0` — успех, `1` — все запросы упали, `2` — неверные аргументы, `130` — прервано Ctrl+C (частичные результаты всё равно печатаются).

## Что выводится

Таблица по каждому запросу (размер, TTFB, полное время, скорость и мини-график) и итог:

- **Average request time** — среднее время запроса, плюс min / median / max и стандартное отклонение;
- **Total downloaded** — общий объём скачанных данных;
- **Download speed** — скорость скачивания.

## Единицы измерения

| Величина | Единица |
|---|---|
| Скорость (основная) | **Мбит/с** — мегабиты в секунду, 1 Мбит = 10^6 бит |
| Скорость (`--unit mbyte`) | МБ/с, 1 МБ = 10^6 байт (1 МБ/с = 8 Мбит/с) |
| Объём | кБ / МБ / ГБ — десятичные (SI), плюс точное число байт |
| Время | мс и секунды |

## Как считается скорость

```
скорость = (суммарно скачанные байты × 8) / суммарное время всех запросов
```

Это взвешенное значение: итоговая скорость не равна среднему арифметическому скоростей отдельных запросов, поэтому короткие быстрые запросы не завышают результат.

Замечания:

- Время запроса — от отправки до полного получения тела ответа (включает DNS, TCP, TLS и TTFB).
- Сжатие отключено (`Accept-Encoding: identity`), поэтому считаются реально переданные по сети байты.
- Запросы не проходят через кеш (`Cache-Control: no-cache`), но CDN всё равно может отдавать файл из своего кеша — первый запрос иногда медленнее.
- Ответы не 2xx и сетевые ошибки показываются в таблице и в статистику не входят.

## Разработка

```bash
npm test         # сборка + юнит- и e2e-тесты (локальный HTTP-сервер)
npm run typecheck
```

Структура:

```
src/
  cli.ts       разбор аргументов, цикл запросов, вывод
  measure.ts   один запрос: TTFB, полное время, байты, таймаут
  report.ts    агрегирование и рендер таблицы / JSON
  stats.ts     min / mean / median / p95 / stddev
  format.ts    байты, время, скорость, цвета
```
